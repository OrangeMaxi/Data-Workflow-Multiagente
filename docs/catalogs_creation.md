# Creación de Catálogos Medallion en Databricks

Se han creado los siguientes catálogos en Databricks para establecer la arquitectura Medallion:

- **bronze**: Para datos crudos e ingesta.
- **silver**: Para datos limpios, validados y enriquecidos.
- **gold**: Para datos agregados y listos para consumo de negocio (BI/ML).

Estos catálogos forman la base de nuestra estrategia de datos y permiten una organización clara y una gobernanza efectiva.
